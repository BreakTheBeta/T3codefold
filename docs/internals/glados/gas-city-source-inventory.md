## Known coverage limits

The catalog records source-backed mechanisms and proposes T3 invariants. It does not establish exhaustive every-line coverage, production reliability, working provider/tool availability, measured model economics, completed external integrations or a complete distributed federation. The main catalog's disagreement ledger takes precedence over simplified guides or adjacent comments where code diverges. Add new concepts with new stable GC IDs; do not count another file as a new concept merely to increase totals.
