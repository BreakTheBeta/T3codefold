# GLaDOS

GLaDOS is an ordinary thread that you promote to coordinator. You talk to it about what you want
done; it plans with you and hands the work to delegated agents, each in its own thread, and is woken
when they finish so it can check the result and report back.

## Set it up

- **Web and desktop:** open the thread you want and choose **Make this thread GLaDOS** from the
  command palette. Choose it again to stop.
- **Mobile:** go to **Settings → GLaDOS** and pick one of your recent threads.

Each machine has one GLaDOS thread. Its model, reasoning level, and permission mode are the thread's
own settings, so change them in the composer like any other thread. Pin it if you want it at the top
of the sidebar.

## Standing instructions

**Settings → GLaDOS** holds standing instructions: priorities, limits, and what good work looks like.
GLaDOS reads them at the start of every turn, so edits apply to its next reply.

Delegated agents appear under GLaDOS's thread like any other delegated task. Open one to follow
its work or answer its questions directly.
